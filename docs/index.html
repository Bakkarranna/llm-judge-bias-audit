Position bias in a language model used as a pairwise judge

Swap agreement and position gap over 288 pairwise comparisons with qwen2.5:1.5b, run locally through Ollama at temperature 0. Every number on this page is read from results/audit.json.

What was measured

24 factual items, each posed as three comparisons: the correct answer against a wrong answer of the same length, against the same answer padded with true detail, and against a wrong answer carrying a citation-like prefix. Every comparison ran twice per pass with the two answers in swapped order, so a preference that only reflects position shows up as a disagreement between the two orderings. Two passes were run: 48 comparisons per pass, 288 model calls in all. The judge never learns which answer is correct; it is asked for a single word and any other reply is counted as unparsed rather than guessed.

The position gap is the win rate of the correct answer when it is second minus its win rate when it is first. A judge that ignores position sits near zero; a negative gap means the answer in the second slot wins more often than the same answer in the first. Swap agreement is the share of items where both orderings of a comparison picked the same answer.

Repeatability

Comparing pass 1 with pass 2 item by item, the judge repeated itself on 24 of 24 items, in every comparison kind Sampling is deterministic, so this measures the protocol, not sampling noise.
